# Central Wisconsin On Tap

Every brewery worth the drive, from Merrill to Amherst. A Wausau Pilot & Review
reader tool: comprehensive free listings, sponsored featured placements.

Static single-file app (Leaflet + vanilla JS), WPR design system, deployed on
GitHub Pages, embedded via iframe. Data: `breweries.json`, hand-validated,
refreshed quarterly. See `CLAUDE.md` for architecture and `REVIEW.md` for the
current validation state.
